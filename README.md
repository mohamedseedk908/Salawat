# 📱 تطبيق صلوات - Salawat App

تطبيق أندرويد إسلامي شامل ومحدث، مصمم بأحدث تقنيات **Native Android** لتوفير تجربة مستخدم سلسة وعصرية للحصول على مواقيت الصلاة والأذكار والعبادات.

---

## ✨ المميزات الرئيسية (Features)

* 🕌 **مواقيت الصلاة:** حساب دقيق لمواقيت الصلاة حسب الموقع الجغرافي (تنسيق Offline وبدون الحاجة لإنترنت مستمر).
* 📖 **الأذكار والعبادات:** قسم متكامل يشمل (أذكار الصباح، أذكار المساء، أذكار الصلاة، والتسبيح).
* 🧭 **الخدمات الإضافية:** التقويم، البحث عن أقرب مسجد، والأدعية المفضلة.
* 🎨 **واجهة مستخدم عصرية:** دعم أنيميشن سلس بين الشاشات شبيهاً بتقليب الصفحات مع تصميم متجاوب تماماً.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **اللغة:** [Kotlin](https://kotlinlang.org/)
* **واجهة المستخدم:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material 3)
* **التنقل (Navigation):** Jetpack Navigation Compose مع Animations مخصصة.
* **إدارة الحالة (Architecture):** Clean Architecture / MVVM.
* **مكتبة مواقيت الصلاة:** Adhan Library.
* **شبكات البيانات:** Retrofit 2 & Gson.
* **تحميل الصور:** Coil 3.
* **مكتبات إضافية:** Google Play Services Location, Accompanist Permissions, Core SplashScreen.
